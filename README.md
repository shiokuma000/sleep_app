# sleep_app

http://127.0.0.1:5000/

┌──────────────────────────┐
│        【1】ユーザー操作（ブラウザ）         │
└──────────────────────────┘
        │
        ▼
① 睡眠時間を選ぶ
        │
        ▼
② 質問が1つずつ表示される
        │
        ▼
③ 各質問に「Yes / No」で回答
        │
        ▼
④ 最後の回答後「診断する」ボタンが出現
        │
        ▼
⑤ ボタンを押す
        │
        ▼
┌──────────────────────────┐
│          【2】サーバー側（Flask）          │
└──────────────────────────┘
        │
        ▼
⑥ `/check` に JSON が送信される  
   { sleep_hours, answers[] }
        │
        ▼
⑦ Flask で回答を集計  
   ・Yes の数を数える  
   ・睡眠時間と回答からアドバイス生成
        │
        ▼
⑧ 結果を JSON で返す  
   { status, yes_count, advice }
        │
        ▼
┌──────────────────────────┐
│         【3】画面に結果を表示（JS）       │
└──────────────────────────┘
        │
        ▼
⑨ クマ画像 ＋ 吹き出し で結果を描画  
   ・状態  
   ・睡眠時間  
   ・Yes数  
   ・アドバイス  
        │
        ▼
⑩ ユーザーが「リセット」を押すと初期状態に戻る
